# Image to MCBE Structure Converter
Converts images to .json files for Minecraft Bedrock Edition and its branches
## Dependencies
- pillow
- numpy
- customtkinter
## How to use
1. Run mc_structure_generator.py
2. Select an image
3. Click Save as JSON
4. Copy the file that was generated into a .json to .mcstructure converter
5. Load it in a structure block
